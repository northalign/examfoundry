# Product Brief 0.9

## Product name

Exam Foundry

## One-sentence description

Exam Foundry helps teachers assemble valid exam papers from structured question banks, while checking mark totals, question types, set works, Areas of Study, audio, scores, and export readiness.

## Version 0.9 positioning

Version 0.9 is a restricted internal Stonyhurst College build.

It is not the commercial or public-release product. It is a focused working version designed to prove the core architecture and user experience.

## Primary user

A music teacher or Director of Music assembling a mock, specimen, internal assessment, or practice paper.

The user needs to move quickly, but cannot risk creating an invalid paper.

## Core user need

The user wants to select questions from previous or prepared materials and assemble them into a valid Edexcel A level Music paper without having to remember all structural rules manually.

## Version 0.9 scope

Exam Foundry 0.9 supports:

- Edexcel
- A level
- Music
- Paper construction
- Question selection
- Sub-question editing for Questions 1 to 3
- Paper validation
- Audio and score asset indicators
- Stonyhurst internal branding
- Neutral branding mode
- A placeholder for future question writing tools

## Future direction

Version 1.0:

- Add Edexcel GCSE Music.
- Add audio stitching for GCSE-style workflows.
- Keep Edexcel-only scope.

Version 1.2 to 1.3:

- Add export and import of data packs.
- Allow protected internal data packs to be imported into an otherwise clean build.
- Prepare for separation between Stonyhurst internal builds and public-release builds.

Version 2.0:

- Add other boards.
- Add wider templates and paper architectures.
- Prepare a public release without bundled copyrighted materials.
- Allow schools to import their own data packs where they have appropriate rights.

## Brand strategy

The app should support three brand modes:

1. Stonyhurst internal
2. Neutral
3. Custom school or organisation

Stonyhurst branding must be tasteful and removable. Do not bake brand assets into core logic.

## Success criteria for 0.9

A successful v0.9 allows the user to:

- Open the app.
- See that it is locked to Edexcel A level Music.
- Select a question for each required slot.
- See instantly whether the paper is valid.
- Understand exactly why a paper is invalid.
- Edit sub-questions for Questions 1 to 3.
- Reach a valid paper state.
- Preview or prepare for export.
- Navigate to a question editor.
- See a clear placeholder for future AI-assisted question writing.

## Non-goals for 0.9

- Perfect public release polish.
- Full exam-board coverage.
- Full data-pack import system.
- AI integration.
- Automated question generation.
- Automatic audio editing.
- Cloud collaboration.
